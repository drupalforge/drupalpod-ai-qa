# Custom Modules

This repository includes custom Drupal modules under `custom_modules/`.
These modules may be moved out into their own projects eventually.

## Modules in This Section

- [drupalpod_ai_qa](drupalpod-ai-qa.md)
  handles QA-specific AI provider setup inside Drupal
- [drupalpod_build_info](drupalpod-build-info.md)
  exposes build metadata inside the running site

## Why These Modules Matter

The shell scripts build the environment, but these custom Drupal modules help
configure the AI provider and expose build information inside Drupal.
